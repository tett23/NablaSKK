# ADR 0007: 設定アプリのアクセシビリティ監査の残りの指摘に対応する

ステータス: 採択

## 文脈

`docs/audit/2026-10-12-preferences-accessibility.md` の指摘のうち、[ADR 0006](0006-preferences-accessibility-fixes.md)(v1.1.1)で
見送ったものが残っている。

- **A-4(中)サイドバーが一覧として読まれない**: サイドバーはボタンを縦に並べた独自の
  部品で、VoiceOver では 6 個のボタンが並んでいるだけに聞こえ、「設定のページの一覧」で
  あることも何番目かも伝わらない。矢印キーで項目を移動できない。`List` に戻すとクリックで
  切り替わらなかった経緯がある([ADR 0005](0005-fix-sidebar-selection-highlight.md))。
- **C-6(低)無効化した辞書の行が薄い**: 「辞書」ページで無効にした行は、行全体を不透明度
  0.5 にしており、文字のコントラストがライトモードで 3.07:1 になる。無効であることは
  チェックボックスでしか分からず、色の薄さに頼っている。
- **C-9(低)ツールチップだけにある情報**: 次はマウスを載せないと分からない。
  - 「辞書」ページのチェックボックスの意味(「チェックを外すと検索対象から外れます」)。
    列の見出しも空欄。
  - 「キー」ページの既定のキー(上書きしている行では、欄に上書きした値が入り、既定値は
    ツールチップの「デフォルト: ...」にしかない)。
  - 並べ替えのつまみ(「ドラッグして並べ替え」)。
- **T-1(低)10pt の文字**: [ADR 0006](0006-preferences-accessibility-fixes.md) で補足文は 11pt にしたが、「キー」ページのシンボル名
  (`SKK_JMODE` など)と「ユーザー辞書」の「送り」バッジは `.caption2`(10pt)のまま。
- **O-3(未確認)キーボードと VoiceOver での実機確認**: 監査は画面録画の権限がない環境で
  行い、VoiceOver の読み上げとフルキーボードアクセスでの操作は確かめていない。[ADR 0006](0006-preferences-accessibility-fixes.md) の
  ラベルも実機の VoiceOver では確認していない。

また [ADR 0006](0006-preferences-accessibility-fixes.md) の実装で、一覧の行を選ぶための背景のボタンを読み上げから外し、代わりに
「この行を選択」という VoiceOver の操作を付けた。フルキーボードアクセスではこのボタンに
Tab でフォーカスが移るが、読み上げからは隠れているので、何のボタンか分からない。

## 実装すること

### 1. サイドバー(A-4)

- サイドバー全体を一つのまとまり(`accessibilityElement(children: .contain)`)にし、
  「設定のページ」という名前を付ける。
- 各項目に「{n} / 6」(ページの順番と総数)を値(`accessibilityValue`)として付ける。
  選択中の `.isSelected` は今のまま。
- サイドバーにキーボードのフォーカスがあるとき、↑↓ キーで前後のページへ移る
  (`onMoveCommand`)。端では止まる(循環しない)。サイドバーはフォーカスを受け取れる
  ようにする(`focusable()`)。
- `List` には戻さない。今のボタンの並びのまま、上の三つを足す。

### 2. 無効化した辞書の行(C-6)

- 行全体の不透明度 0.5 をやめる。
- 無効の行は、辞書名を補足の色(`PreferencesPalette.secondary`、ライト 5.74:1)にし、
  名前の後ろに「(無効)」と書く。種類・場所の欄は通常の見た目のまま。
- VoiceOver では、チェックボックスの名前(「{辞書名}を検索に使う」)と状態で無効が伝わる。

### 3. ツールチップだけの情報を画面にも出す(C-9)

- 「辞書」ページのチェックボックスの列見出しを「使う」とし、ページの説明文に
  「チェックを外した辞書は検索しません」を足す。チェックボックスの `accessibilityHint` にも
  同じ意味を入れる。
- 「キー」ページで上書きしている行は、欄の下に「デフォルト: {既定のキー}」を補足の色で
  出す。
- 並べ替えのつまみは読み上げから隠したままにし、「辞書」ページと「ユーザー辞書」ページの
  説明文に「行の先頭の ≡ をドラッグするか、↑↓ ボタンで並べ替えられます」を足す。

### 4. 10pt の文字(T-1)

- 「キー」ページのシンボル名と「ユーザー辞書」の「送り」バッジを 11pt(`.subheadline`)に
  する。

### 5. 行を選ぶボタン

- 一覧の行の背景のボタン([ADR 0006](0006-preferences-accessibility-fixes.md) の `SelectableRow`)を読み上げから隠すのをやめ、
  「{行の名前}を選択」という名前を付ける(「辞書」ページは辞書名、「ユーザー辞書」の候補は
  候補の単語。空なら「{n} 番目の候補を選択」)。フルキーボードアクセスでも VoiceOver でも
  同じボタンで行を選べるので、「この行を選択」の操作は外す。
- 名前の文言は `PreferencesAccessibility` に足す。

### 6. 実機での確認と再監査(O-3)

- 実装のあと、作業者に VoiceOver とフルキーボードアクセスでの確認を依頼する。確認の
  手順(下のテスト設計の「実機での確認」)をそのまま渡す。
- 結果を新しい監査の記録 `docs/audit/<日付>-preferences-accessibility-recheck.md` に残す。
  元の監査の記録は変えない。

## 実装しないこと

- サイドバーを `List` や `NavigationSplitView` に戻すこと。
- macOS の文字サイズ設定への追従、色やレイアウトのほかの変更。
- ツールチップの削除(画面に出したものも、ツールチップは残す)。
- エンジン・IME の変更。

## テスト設計

先に書いて失敗させてから実装する。

- ラベル(`sh macos/run-tests.sh`): `PreferencesAccessibility` に足す「{名前}を選択」
  (空のときの「{n} 番目の候補を選択」を含む)、サイドバーの「{n} / 6」の文言。
- サイドバーのキーボード操作(`sh macos/run-ui-tests.sh`): 画面外のウィンドウで
  サイドバーにフォーカスを置き、↓ キーで次のページ、↑ キーで前のページに切り替わる
  (`selectedSettingsPane` の値と、強調される行の画素)。最後のページで ↓、最初のページで
  ↑ を押しても変わらない。
- 無効化した辞書の行(`sh macos/run-ui-tests.sh`): 無効の行の辞書名の画素が補足の色で、
  「(無効)」の文字が出ている(行の文字の画素が不透明度 0.5 の薄さでない)。
- 「キー」ページ(`sh macos/run-ui-tests.sh`): 上書きしている行の欄の下に補足の色の
  画素(「デフォルト: ...」)が現れ、上書きしていない行には現れない。
- 既存のテストがすべて通ること。
- 実機での確認(自動化できないもの。作業者に依頼し、再監査の記録に残す):
  - VoiceOver(Command + F5)で、サイドバーが「設定のページ」として読まれ、各項目の
    「{n} / 6」と選択状態が読まれる。
  - VoiceOver で、[ADR 0006](0006-preferences-accessibility-fixes.md) と本 ADR のラベル(アイコンだけのボタン、辞書の行の部品、
    ローマ字・キーの欄、行を選ぶボタン、組み込みのルール)が日本語で読まれ、装飾の
    アイコンが読まれない。
  - フルキーボードアクセス(システム設定 → キーボード)で、Tab で全ページの部品を順に
    たどれる。サイドバーで ↑↓ が効く。一覧の行を選ぶボタンで行を選び、↑↓・削除の
    ボタンを使える。

## トレードオフ

- サイドバーは `List` の意味(行・一覧)を持たないまま、まとまりの名前と「{n} / 6」で
  補う。VoiceOver の一覧としての操作(行の移動など)は得られないが、クリックで確実に
  切り替わる今の作りを保てる。
- 行を選ぶボタンを読み上げに出すので、VoiceOver で一覧をたどると行ごとに要素が一つ増える。
  代わりに、キーボードと VoiceOver の両方で同じ方法で行を選べる。
- 無効の行を「(無効)」と書くと、辞書名の列の幅を少し使う。名前が長い辞書は、今より早く
  省略表示になる。
